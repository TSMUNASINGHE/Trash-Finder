Instructions
  • This is a community run project. Please be truthful.
  • Click on the map above and go to the page containg the map.
  • Click on the map to choose the location of trash and then click Add Trash Location button to proceed. After clcking this do not go back as it may cause errors
  • If you have an image insert it (jpeg, jpg or png ONLY), if not click the "No picture available" button.
  • If you add an incorrect file type and click upload, the coordinates will not be added.
  • Click "Upload" or "No picture available", or the location will not be added.
  • When you clean up a location just click on the marker and click the "Cleaned" button on the pop up.
  • Clicking this will delete the marker, so only do so if the area is truly clean.
